## What it does

`main.ts` writes one funny single-line one-star review, written in the voice
of a house cat about its human, to `/output/entry.txt`:

> One star. He installed a cat flap, then locked it the first time I used it at 3 a.m. The flap was his idea. The 3 a.m. was mine.

The line is 128 characters: a specific, recognisable complaint (the cat flap),
an unmistakably feline voice, and a sting in the last few words, all in the
deadpan shape of a real one-star review.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (one line, no trailing newline).
